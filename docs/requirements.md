# bookPotter 项目需求与愿景

## 项目简介
bookPotter 是一个面向小学一年级学生的阅读 Web 应用。通过将知名小说改写为低龄可读文本，配合拼音/音标提示和生字记录，帮助孩子在好奇心驱动下理解故事内容。

## 目标
- 让一年级学生能读懂并喜欢故事
- 保持故事核心内容、降低词汇难度
- 支持中文简化阅读，后续可扩展英文展示
- 采用 serverless 纯前端架构，数据存储可用阿里云 OSS

## 主要功能
- 故事文本展示与简化版对照
- 生字/生词点击显示拼音或音标
- 用户学习数据存储于阿里云 OSS
- 界面简洁明快，适合低龄儿童阅读

## 技术方案
- 前端：原生 HTML / CSS / JS
- UI：可使用 Element Plus CDN 简化界面样式
- 后端：无服务器架构，暂不依赖自建服务
- 存储：阿里云 OSS（对象存储）

## 开发阶段
1. 初始化项目结构和 Git 仓库
2. 设计页面展示与简化文本渲染
3. 实现生字点击交互和拼音提示
4. 集成 OSS 存储用户数据
